# Master Design Document — TEMPLATE

*Structure adapted from the Georgetown SCS Master Design Document. Two adaptations for a non-graded program: (1) no grading — replaced with "Assessment / How Success Is Measured"; (2) curated source media is not re-listed here — it lives in the pre-class study guides, so the Materials column points there. Use `<Created>` to mark media/artifacts that still need to be built.*

## How to use this template
1. Fill the **Course-Header Block** once.
2. Add one **Module Table** per module/week.
3. Keep activities **named and concrete** (what students actually *do*), not vague ("students practice").
4. The minute-by-minute session timing does **not** go here — it lives in the **Teaching Guide**. The MDD says *what* happens; the Teaching Guide says *how/when* to deliver it.

### Legend / conventions
- **→CO#** — every module objective is tagged to the course objective it ladders up to.
- **<Created>** — media or an artifact that must be produced (notebook, cheat sheet, custom video). Unmarked = already exists / curated.
- **Materials → Study Guide** — curated readings/videos live in that module's pre-class study guide; reference it rather than duplicating links.
