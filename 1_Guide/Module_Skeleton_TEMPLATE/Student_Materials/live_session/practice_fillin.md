> TEMPLATE STUB — The 'we do' rung: structure given, the DECISIONS left blank for students to fill.
>
> _Code → fill-in-the-blank code (`____`)   ·   Hands-on → partial worksheet with the settings blank   ·   Writing/analysis → a draft with the key moves removed_

**How to degrade well:** blank the *decisions*, not the syntax. Use a variant dataset or scenario so it isn't recall. Four to eight blanks is usually right. Print the expected result beside each blank, so a student can tell they're right without you in the room.
