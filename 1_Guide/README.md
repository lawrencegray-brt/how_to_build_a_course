# Course Master — The Guide

A self-serve, step-by-step method anyone can follow to build a high-quality course.

## Start here
1. **`Start_Here.pdf`** — the whole idea in plain language, one page. **New? Read this first.**
2. **`How_To_Build_A_Course_GUIDE.pdf`** — the full method, step by step (begin at "Why I Wrote This"; Bloom's verbs and a question bank are in the appendices).
3. **`Method_on_a_Page.pdf`** — a one-page quick-reference to keep beside you *once you know the method* (shorthand, not an introduction).

## What's included
- **`Start_Here.pdf`** — the plain-language overview (read first).
- **The Guide** (`How_To_Build_A_Course_GUIDE.pdf`) — the full method.
- **`Method_on_a_Page.pdf`** — a one-page quick-reference, for recall once you know the method.
- **`templates/`** — a blank form for each step: Decisions, Objectives, Seven-Practices audit, **Decompose worksheet**, Master Design Document, and a Teaching-Guide segment.
- **`Module_Skeleton_TEMPLATE/`** — a folder to copy for each module. Its file names are generic on purpose — they don't assume what kind of course you're building, so rename each one to your course's form.
- **`Contact_Hour_Companion.pdf`** — a tool for sizing a course to its real schedule.
- **`visuals/`** — the diagrams embedded in the Guide.
- **`Learning_About_Instructional_Design.pdf`** — optional companion reading; not needed to build a course.

## How to use it
Follow the guide top to bottom for one module first: write your Decisions doc, your objectives, run the practices audit, build the Master Design Document, lay out the three-package module, produce with GenAI (under the guardrails), and review with the Review Council. The blank templates are in `templates/`; when a step feels abstract, see the **Worked Examples** package.
