# How to Build a Course

**A step-by-step method for building a course that someone else could pick up and teach — written for subject-matter experts, not professional instructional designers.**

You bring the expertise. This brings the structure.

## The templates you'll actually fill in

Each is a blank form for one step of the method. They ship as both `.docx` (fill it in Word) and `.md` (plain text).

| Template | Used in |
| --- | --- |
| [Decisions](1_Guide/templates/Decisions_TEMPLATE.md) | §1 — the one page everything else inherits |
| [Objectives](1_Guide/templates/Objectives_TEMPLATE.md) | §2 — what students will be able to *do* |
| [Seven-Practices Audit](1_Guide/templates/Seven_Practices_Audit_TEMPLATE.md) | §3 — find the gaps before you build |
| [Decompose Worksheet](1_Guide/templates/Decompose_TEMPLATE.md) | §3.5 — objectives into modules |
| [Master Design Document](1_Guide/templates/MDD_TEMPLATE.md) | §4 — the blueprint |

And a blank **[module folder](1_Guide/Module_Skeleton_TEMPLATE/)** to copy once per module.

## The one-line version

**Decisions → objectives → seven practices → design document → the three-package module → produce with AI under guardrails.**

And the rule the whole line hangs on: **decide before you produce.**

---

## Who this is for

Anyone who knows a subject and has been asked to teach it — and who would rather not guess. You do not need a teaching background, and you do not need to know git: the download link above gives you every file.
