# 01 — Decisions Document (filled example)

*This is the lean, one-page Decisions document for Intro-to-ML. It's the foundation every later choice — and every GenAI prompt — inherits.*

- **Audience:** Domain experts (not software engineers); prior stats, basic Python, high-school math. Not expected to know calculus/gradients.
- **Objective:** Production-ready code, not theory. Students *use* gradient descent; they don't derive it.
- **Depth rule:** Only as deep as an MVP project requires. Math is surface-level/visual only.
- **Datasets:** Best canonical dataset per problem type (Week 1 = California Housing). Public datasets only — no proprietary data.
- **Algorithms:** Linear Regression (W1) … XGBoost in; SVM/KNN out.
- **Frameworks:** sklearn (W1–5), Keras 3.x (W6–8).
- **Tone:** Welcoming, whole-person. Hints remind of conceptual purpose; never give the answer.
- **Scaffolding:** Live = complete code → Pair = fill-in-blank (~70% provided W1) → Homework = scaffolded TODOs.
- **Time:** 30 min pre-class + 3 hr live + 30 min post-class.
- **Values:** *Quality* — every practice file is derived from a solution that runs, so students never debug my mistakes. *Humanity* — hints remind, never hand over; nobody is made to feel behind. *Integrity* — we verify AI output in class, because plausible is not correct.
