# Home Coffee Brewing — Master Design Document

*Built following Guide §4 and MDD_TEMPLATE.md. Course-header block + one module table per module. Conventions: →CO# = objective ladder; `<Created>` = artifact still to build; curated media → the pre-class study guide.*

## Course-Header Block

| Field | Content |
| --- | --- |
| **Course Name** | Introduction to Home Coffee Brewing (Pour-Over) |
| **Course Description** | A hands-on beginner course for making café-quality pour-over coffee at home and adjusting it to your taste. Practical and tasting-driven, not chemistry. |
| **Course-Level Objectives** | CO1 (Apply) Brew a repeatable pour-over. / CO2 (Analyze) Diagnose a flawed cup. / CO3 (Evaluate) Adjust toward your taste. / CO4 (Understand) Explain grind/temp/ratio → extraction. / CO5 (Apply) Select & store fresh beans. |
| **Values (mapped)** | *Quality:* every recipe tested to a reference cup. *Humanity:* low-shame, beginner-friendly, no snobbery. *Integrity:* honest about what's preference vs. what's a mistake. |
| **Teaching Principles (applied)** | See `03_Seven_Practices_Audit.md` — one model (grind+water+ratio→extraction→taste); reference-brew benchmark; in-session tasting feedback; brew-log for self-direction. |
| **Assessment / How Success Is Measured** | No grades. Success = a brewed cup that hits the reference in session; a completed week-long brew log; passing the tasting self-assessment. |
| **Materials & Media** | Curated videos/readings → each module's pre-class study guide. Tools: dripper, filters, kettle, scale, burr grinder, timer. |
