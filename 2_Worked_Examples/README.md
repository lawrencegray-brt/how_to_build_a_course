# Course Master — Worked Examples

Two real courses built with the method, as models to copy from. One **code** course and one **non-code** course — to show the method works for any subject.

## What's here
- **`IntroML/`** — a code course (Introduction to Machine Learning). Syllabus, Decisions doc, objectives, Master Design Document, a three-package module skeleton, and one fully-shown teaching segment.
- **`Coffee/`** — a non-code course (Home Coffee Brewing). The same set, plus a seven-practices audit and a non-code scaffolding example (fill-in-the-blank without code).

## How to read either one
Open the files in number order: `00_Syllabus` → `01_Decisions` → `02_Objectives` → (`03_…audit`) → `04_MDD` (or `03_Sample_MDD`), then the module skeleton, then the fully-shown segment.

*Surface-level by design:* these are worked examples, not fully built courses — most files inside the module skeleton are stubs that show structure, with one artifact shown at full depth so you can see the difference.

*Pairs with the **Guide** package — each example follows the guide's sections in order.*
