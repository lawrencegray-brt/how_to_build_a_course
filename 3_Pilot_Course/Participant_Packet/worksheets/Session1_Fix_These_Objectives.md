# Worksheet — Session 1: Fix These Objectives

*Pair work. For each weak objective, name **what's wrong** — the failure mode (not measurable / instructor-focused / activity-not-learning / inflated verb). The **strong rewrite is shown** so you can see how each one flips; study the move. On the **last** one, you write the rewrite. Then write one or two of your own. (Everyday topics on purpose — the skill is the same in any subject.)*

## Spot the flaw (rewrite shown)

1. **Weak:** "Students will understand what makes a good presentation."
   > **What's wrong?** ________
   > **Strong:** "Identify three features of an effective presentation."

2. **Weak:** "Provide an overview of the onboarding process."
   > **What's wrong?** ________
   > **Strong:** "Complete the onboarding checklist for a new hire."

3. **Weak:** "Watch the active-listening training video."
   > **What's wrong?** ________
   > **Strong:** "Paraphrase a speaker's point to confirm understanding."

4. **Weak:** "Students will design an original leadership framework from first principles." *(audience: new managers)*
   > **What's wrong?** ________
   > **Strong:** "Apply a standard 1-on-1 template with a direct report."

5. **Weak:** "Students will know the parts of a good email."
   > **What's wrong?** ________
   > **Strong:** "List and describe the parts of a well-structured email."
