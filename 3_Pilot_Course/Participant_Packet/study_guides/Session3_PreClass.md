*~30 minutes.*

## Do this before Session 3
1. **Decompose your course on the worksheet, then build your Master Design Document from it** (Deliverable B). All seven steps first, for every course objective — as you saw it filled for coffee; then bring the module list across into the MDD, add topics and materials, name the activities, and check it against **Rubric 5.2** before you call it done.
2. **Choose the ONE module you'll build.** Just one — not the whole course.
3. **Have your Decisions doc in hand.**
4. **Read the guide, Section 5 (the three packages)** — including the accessibility (UDL) part.
5. **Unzip the two module folders beside your bundles.** `Coffee_Module1_filled.zip` is the coffee course's Module 1 — the three packages laid out, every file named, three built to depth (the reference brew, the paired fill-in card, one gold-tier segment). `Module_Skeleton_TEMPLATE.zip` is the blank version of the same thing; in class you will unzip it inside your course folder and make it yours. Glance at the coffee one before class.
6. **Make your course a folder.** Put your Decisions doc, your Objectives and your MDD together at the root of one folder — that is what an agent reads. Copy `AGENT_INSTRUCTIONS.md` (from `templates/`) in beside them and rename it for your tool:
    - rename it `AGENTS.md` — the universal name; VS Code Copilot, Codex and most agents read it
    - Claude Code → `CLAUDE.md`

    Then run the trace-back on it — **AI-4.1**, the way you saw in class: *"Read the Objectives doc and the MDD in this folder. Report each →CO# tag that points at no course objective, and each course objective no module serves. List only, with file paths. Change nothing."* **Bring what it flagged.** *(No agent tool? Paste the chat version from the Directing AI card — same test, same answer.)*
