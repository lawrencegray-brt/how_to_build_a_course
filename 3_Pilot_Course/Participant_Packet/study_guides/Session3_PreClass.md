# Pre-Class — Session 3 (Structure the Module)

*~30 minutes.*

## Do this before Session 3
1. **Finish your Master Design Document** (Deliverable B).
2. **Choose the ONE module you'll build.** Just one — not the whole course.
3. **Have your Decisions doc in hand.**
4. **Read the guide, Section 5 (the three packages)** — including the accessibility (UDL) part.
5. **Open a worked example's module skeleton** — the Coffee example's `Module1_folder_skeleton/` — to see the three packages laid out, and look at the one fully-shown segment.
6. **Make your course a folder.** Put your Decisions doc, your Objectives and your MDD together at the root of one folder — that is what an agent reads. Copy `AGENT_INSTRUCTIONS.md` (from `templates/`) in beside them and rename it for your tool:
    - VS Code Copilot → `.github/copilot-instructions.md`
    - Claude Code → `CLAUDE.md`
    - most others → `AGENTS.md`

    Then run the trace-back on it — **AI-4.1**, the way you saw in class: *"Read the Objectives doc and the MDD in this folder. Report each →CO# tag that points at no course objective, and each course objective no module serves. List only, with file paths. Change nothing."* **Bring what it flagged.** *(No agent tool? Paste the chat version from the Directing AI card — same test, same answer.)*
