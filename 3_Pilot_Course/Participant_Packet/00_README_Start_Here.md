# Participant Packet — Start Here

Welcome to **The Course Master Method.** Over five weeks you'll build a real course on a subject of your choice. This packet has everything you need.

## Read in this order
1. **01_Participant_Syllabus** — the schedule, your three deliverables, and what's due when.
2. **How_To_Build_A_Course_GUIDE** — the method itself (your reference all five weeks; Bloom verbs + practice questions are in its appendices).
3. **The worked examples** — when a step feels abstract, open one and copy the pattern.

## What's in the packet

Everything below is a link. The packet sits inside the course folder, so a few
items live one level up — those links point there, and the path is written out
so you can also just navigate to it.
