# Decompose Into Modules — WORKSHEET (TEMPLATE)

*Guide §3.5. Work top to bottom. Do **Steps 1–2 for every course objective first**, then cluster — clusters cross CO boundaries (a module often serves several COs), so the whole pool has to exist before modules emerge. The **module list** at the bottom is the output; it feeds the MDD (§4).*

## Step 3 — cluster the whole pool into modules
*Sketch a concept map of **all** the module objectives above; related ones group together, and each group is a candidate module (a coherent concern — a theme, a capability, a week). Cross-CO groups are expected.*

## Step 4 — sequence by prerequisite
*Order the modules so each builds on the one before (this ordering also threads your module intros/conclusions).*

## Step 5 — surface each module's features (seven practices)
*For each module, examine its objectives and name the features it needs — its hook, worked example, practice, slice of the map, etc. These + the evidence are what you size next, and they populate the MDD's Activities/Materials.*

## Step 6 — coarse fit-check
*Ballpark each module's features + evidence against your container (session length × number of sessions). Benchmark the concrete pieces (a practice rep ~15–20 min, a video at its length, a reading by pages) with the Contact-Hour companion. Rough by design — you only need fits / too big / too thin.*
