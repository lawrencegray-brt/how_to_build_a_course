## Model — the coffee course, done

*Notice the **kind** of feature each practice becomes:*

| Practice | The feature (coffee) |
| --- | --- |
| Activate Prior Learning | a first-day **exercise** — recall a disappointing cup, then explain why |
| Organize Knowledge | a **concept map** — the course on one diagram, every variable a lever on "extraction" |
| Motivate | an opening **hook** — "great coffee at home for pennies," a real tasting in session 1 |
| Develop Mastery | a curated **reference video** of a great brew — what to aim at |
| Practice & Feedback | a paired **brew-along** with tasting feedback, then a week-long brew log |
| Student Development & Climate | **norms** — "everyone's made a bad cup"; low-shame, no snobbery |
| Self-Directed Learners | a take-home **recipe card** + resource list |
